# 《旧历重临》（暂定名）

**题材**：中式民俗无限流（悬疑惊悚 + 幽默爆笑）
**核心设定**：现世的封印与旧历（诡异世界）的重临。主角在诡异世界中求生，带出带有“行为禁忌”代价的诡物，在现世与旧历的交错中挣扎与破局。
**整体基调**：在极度高压的生死危机中，由于主角（以及其他人）不得不遵守诡物带来的“奇葩行为禁忌”，或者利用这些荒谬规则卡系统 Bug，从而产生强烈的反差萌和令人捧腹的爆笑效果。

## 简介
我们所处的现代唯物主义社会，是一个巨大的“无菌封印区”。但在现世之外，那些被人类淘汰、恐惧的阴间民俗和野蛮祭祀，化作了无数个“诡异世界”。
地下典当行的朝奉赵阳，因意外卷入诡异世界。他凭借毒辣的眼力、极致的市井实用主义，在充满致命禁忌的诡异世界中求生。他将利用诡物的“规则类限制”代价，撬动最大的破坏力，在守陵人与降临会的阵营倾轧中，杀出一条血路，直面千年前绝地天通的真相。
