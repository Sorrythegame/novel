# 《旧历重临》（暂定名）

**题材**：中式民俗无限流
**核心设定**：现世的封印与旧历（诡异副本）的重临。主角在诡异副本中求生，带出带有“行为禁忌”代价的诡物，在现世与旧历的交错中挣扎与破局。

## 简介
我们所处的现代唯物主义社会，是一个巨大的“无菌封印区”。但在现世之外，那些被人类淘汰、恐惧的阴间民俗和野蛮祭祀，化作了无数个“诡异副本”。
地下典当行的朝奉赵阳，因意外卷入副本。他凭借毒辣的眼力、极致的市井实用主义，在充满致命禁忌的副本中求生。他将利用诡物的“规则类限制”代价，撬动最大的破坏力，在守陵人与降临会的阵营倾轧中，杀出一条血路，直面千年前绝地天通的真相。
